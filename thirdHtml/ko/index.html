실시간 VLM 스트리밍

대규모 비전-언어 모델이 실시간으로 영상 스트림을 시청하고 — 스트리밍 출력으로 프레임 단위로 장면을 이해합니다.

1
영상 스트림 입력

RTSP / WebCam / 파일, 15~30 FPS. 프레임 드롭 없는 연속 캡처.

2
프레임 스케줄러

지능형 프레임 스키핑 및 균일 샘플링. AI 과부하를 방지하는 흐름 제어.

3
VLM 추론

LLaVA, Qwen-VL, InternVL — 모든 오픈소스 비전 모델. 추가 학습 불필요.

4
스트리밍 출력

밀리초 단위의 실시간 응답. 영상이 끝날 때까지 기다리지 않습니다.

01

주석

검출, 세그멘테이션, 분류를 위한 내장 라벨링. 품질 보증이 포함된 협업 워크플로.

02

학습

AutoML 또는 완전 수동 제어. 동적 리소스 스케줄링을 통한 분산 GPU 학습. TensorFlow/PyTorch 모델 가져오기.

03

최적화

17가지 형식으로 내보내기: ONNX, TensorRT, CoreML, TFLite, OpenVINO 등. 엣지를 위한 양자화 및 가지치기.

04

배포

브라우저에서 검증 후 원클릭 원격 배포. OTA 업데이트, A/B 테스트, 롤백, 실시간 성능 모니터링.

자체 개발 VLS 프로토콜

영상 IoT에 특화된 설계. 저지연, 극한의 패킷 손실 내성, 범용 호환성.

영상 전송

  • VLS 프로토콜: TCP 기반, <1.2초 지연, 30% 손실에서도 끊김 없음
  • WebRTC P2P: 밀리초 단위 상호 연결, 70% 대역폭 절감
  • 멀티 프로토콜: HLS, FLV, RTSP, GB28181 — 모든 단말기
  • 인코딩: H.264/H.265, 4K/1080p/720p 적응형

IoT 및 제어

  • MQTT: 디바이스로의 투명한 명령 전송
  • IoT 센터: 주변장치를 위한 TCP/IP 4G 네트워크 기능
  • 객체 모델: 표준화된 디바이스 설명 및 동기화
  • 융합: 영상 스트림 + 센서 데이터 결합 알림

보안 및 규정 준수

  • GB28181: 국가 감시 표준
  • GB35114: 강화 보안 인증
  • 암호화: 전송 중 및 저장 데이터 보호
  • 감사: 전체 작업 로깅 및 접근 제어

어디든 배포 가능

프라이빗 클라우드, 하이브리드, 에어갭 환경. 데이터가 네트워크를 벗어나지 않습니다. x86 및 ARM 지원.

온프레미스

민감한 환경을 위한 완전한 에어갭 지원. 자체 인프라에서 완전한 데이터 주권을 확보합니다.

curl -fsSL https://get.vlstream.dev | bash

Docker

Docker Compose로 원클릭 배포. GPU 패스스루를 포함한 전체 스택을 5분 만에 실행합니다.

docker compose up -d

Kubernetes

자동 스케일링, HA 클러스터링, 로드 밸런싱, 자동 장애 조치를 갖춘 프로덕션 Helm 차트.

helm install vlstream oort/vlstream
