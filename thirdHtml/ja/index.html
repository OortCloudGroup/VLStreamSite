独自開発VLSプロトコル

映像IoTのために専用設計。低遅延、極限のパケット損失耐性、汎用互換性。

映像伝送

  • VLSプロトコル：TCPベース、<1.2秒遅延、30%損失でもカクつきなし
  • WebRTC P2P：ミリ秒単位相互接続、70%帯域幅削減
  • マルチプロトコル：HLS、FLV、RTSP、GB28181――全端末対応
  • エンコーディング：H.264/H.265、4K/1080p/720p適応

IoT＆制御

  • MQTT：デバイスへの透過的コマンド伝送
  • IoTセンター：周辺機器向けTCP/IP 4Gネットワーク機能
  • オブジェクトモデル：標準化されたデバイス記述＆同期
  • 融合：映像ストリーム＋センサーデータの統合アラート

セキュリティ＆コンプライアンス

  • GB28181：国家監視規格
  • GB35114：強化セキュリティ認証
  • 暗号化：転送時および保存時のデータ保護
  • 監査：完全な操作ログ＆アクセス制御

どこにでもデプロイ可能

プライベートクラウド、ハイブリッド、またはエアギャップ環境。データがネットワークから出ることはありません。x86およびARM対応。

オンプレミス

機密環境向けの完全エアギャップ対応。自社インフラ上で完全なデータ主権を確保。

curl -fsSL https://get.vlstream.dev | bash

Docker

Docker Composeによるワンクリックデプロイ。GPUパススルー対応のフルスタックを5分で起動。

docker compose up -d

Kubernetes

本番用Helmチャート。オートスケーリング、HAクラスタリング、ロードバランシング、自動フェイルオーバー対応。

helm install vlstream oort/vlstream
